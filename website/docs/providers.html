AI providers

DearDiary doesn't run its own cloud. Your screenshots go to exactly one place: the AI provider you configure. Pick by budget and privacy preference.

ProviderCostBest for
Google GeminiFree tier covers typical useEasiest start
Anthropic ClaudeAPI usage (cents/day)Best summaries & chat
OpenAI / compatibleAPI usageExisting OpenAI users, LM Studio
OllamaFreeFully offline privacy

Google Gemini (recommended start)

  1. Visit Google AI Studio and create a free API key.
  2. In DearDiary: Settings → AI provider → Google Gemini, paste the key.
  3. Click Save & test connection.

Default model: gemini-2.5-flash — fast, vision-capable, and generous on the free tier.

Anthropic Claude

  1. Create an API key in the Anthropic Console.
  2. Select Anthropic Claude in Settings and paste the key (sk-ant-…).

DearDiary uses structured outputs with Claude, which makes timeline extraction especially reliable. Analysis costs are typically a few cents per working day.

OpenAI or any compatible endpoint

  1. Select OpenAI (or compatible) in Settings.
  2. Paste your key, and adjust the Base URL if you're using a compatible server (LM Studio: http://localhost:1234/v1).
  3. Pick a vision-capable model (e.g. gpt-4o-mini).

Ollama — fully offline

  1. Install Ollama for Windows.
  2. Pull a vision model: 
    ollama pull qwen2.5vl
  3. Select Ollama (local) in Settings. Default URL http://localhost:11434/v1.
With Ollama, screenshots never leave your machine — the complete privacy option. A GPU with ≥8 GB VRAM makes analysis comfortably fast; smaller machines work with more patience.

Switching providers

Change any time in Settings — it only affects future analysis batches. Your existing timeline is already stored as text and stays untouched.
